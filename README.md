# 🤖 Projeto Android

Este projeto foi criado como parte dos estudos iniciais de HTML e CSS. É uma landing page temática sobre o mascote do sistema Android, utilizando técnicas básicas de estruturação e estilização.

## 🔧 Tecnologias Utilizadas

- HTML5
- CSS3
- Layout com imagens e textos

## 🎯 Funcionalidades

- Página informativa sobre o Android.
- Design simples e intuitivo.
- Responsividade básica.
